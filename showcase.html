输入模式与乐器推断

两种模式 --mode

stems（默认）分轨直入 · 跳过分离模型
separate成品先分离再混 · 权重缺失时降级

输入不需要指定乐器——只输入轨道即可，引擎按文件名自动推断；需要时才用 path:instrument 显式覆盖。

快速使用

原生 GUI / 主应用 CLI

./target/release/mixer-app          # GUI
./target/release/mixer-app modes    # 当 CLI 用
mixer-app mix --stems a.wav:vocals \
  --stems b.wav:drums -o out.wav

命令行（分轨直入）

mixer-cli mix \
  --stems vocal.wav --stems drums.wav \
  --stems bass.wav -o final.wav \
  --json  # 乐器自动推断

SXSEditor 插件

安装 onemix-mixer-0.1.0.sxsp 后，通过 MCP 或插件面板调用：

onemix-mixer.mixFiles
 {vocalsPath, accompanimentPath,
  outputPath, preset}
